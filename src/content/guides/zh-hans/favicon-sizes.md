浏览器、操作系统和搜索引擎都会以不同尺寸显示网站图标。好消息是：只需少量文件，就能在任何地方都清晰显示。

## 简短回答

对几乎所有网站来说，下面这组文件就足够了：

| 文件 | 尺寸 | 使用场景 |
| --- | --- | --- |
| `favicon.ico` | 32×32（也可包含 16×16 和 48×48） | 所有浏览器、旧版工具、自动发起的 `/favicon.ico` 请求 |
| `icon.svg` | 可缩放 | 现代浏览器，任意尺寸都清晰，可支持深色模式 |
| `apple-touch-icon.png` | 180×180 | iPhone 和 iPad 主屏幕 |
| `icon-192.png` | 192×192 | Android 主屏幕、Web 应用清单 |
| `icon-512.png` | 512×512 | Android 启动画面、可安装的 Web 应用 |

## 常见网站图标尺寸及用途

| 尺寸 | 显示位置 |
| --- | --- |
| 16×16 | 标准分辨率屏幕上的浏览器标签页和书签 |
| 32×32 | 高分辨率屏幕上的浏览器标签页、Windows 任务栏快捷方式 |
| 48×48 | Windows 网站图标；Google Search 建议的最小尺寸 |
| 96×96、144×144 | 高密度屏幕上的 Google Search（48 的倍数） |
| 180×180 | 用于 iOS 和 iPadOS 的 `apple-touch-icon` |
| 192×192 | Android Chrome 主屏幕，也是清单图标的最小尺寸 |
| 512×512 | 用于 PWA 启动画面和应用商店的清单图标 |

## Google Search 的要求

Google 会在搜索结果中将你的网站图标显示在页面旁边。根据 Google 的指南，图标应为**正方形**，至少 **48×48 像素**（或 48 的倍数，例如 96×96 或 144×144），并且位于 Googlebot 可以抓取的稳定 URL 上。SVG 文件也可以使用。过小的图标会被放大，可能显得模糊。

## 让图标清晰锐利的技巧

- **先为最小尺寸设计。** 在 16×16 下只容得下一个简单的形状或一两个字母。请去掉细节和细线条。
- **充分利用整个正方形。** 留白过多的图标在标签页中会显得很小。
- **在浅色和深色背景下测试。** 标签页、搜索结果和主屏幕两种背景都会用到。
- **为 iOS 提供纯色背景。** iOS 会用黑色填充 `apple-touch-icon` 的透明区域。
- **标记可遮罩图标。** Android 可能会把图标裁剪成圆形或圆角方形（squircle）；对于带有安全区域的图标，请在清单中使用 `"purpose": "maskable"`。

## 通过 Favicon.is 获取任意尺寸的图标

当你显示*其他*网站的图标时，请只请求你需要的确切尺寸：

```text
https://favicon.is/github.com?size=32
https://favicon.is/github.com?size=64
https://favicon.is/github.com?larger=true
```

支持的值为 16、32、48、64、128 和 256 像素。图标的清晰度取决于网站发布的最大图标，可以用[网站图标检测工具](../../checker/)检查。
