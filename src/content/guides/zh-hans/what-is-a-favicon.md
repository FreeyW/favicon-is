**网站图标**（Favicon，*favorite icon* 的缩写）是代表一个网站的小图片。你会在浏览器标签页、书签和历史记录、地址栏以及搜索结果旁边看到它；当你把网站保存为快捷方式时，它还会出现在手机主屏幕上。

## 网站图标会出现在哪里

- **浏览器标签页。** 打开很多标签页时，图标往往是区分它们的唯一依据。
- **书签和历史记录。** 有了图标，长长的列表也能一眼扫完。
- **搜索结果。** Google 等搜索引擎会在移动端和桌面端的网站名称旁显示网站图标。
- **主屏幕和应用启动器。** 当有人把你的网站添加到手机上时，触摸图标就会成为应用图标。
- **其他应用。** 聊天应用、稍后阅读服务、密码管理器和仪表盘都会用网站图标来标识链接。

## 简要历史

网站图标由 Internet Explorer 5 于 1999 年引入。该浏览器会在网站根目录中查找名为 `favicon.ico` 的文件，并将其显示在*收藏夹*（Favorites）菜单中，这也是其名称的由来。后来，HTML 加入了 `<link rel="icon">` 标签，让网站可以自行选择图标的位置、格式和尺寸。

如今，一个网站通常会提供多个图标：用于标签页的小尺寸 ICO 或 PNG、可缩放到任意尺寸的 SVG、用于 iOS 的 `apple-touch-icon`，以及在 Web 应用清单中为 Android 列出的大尺寸 PNG 文件。

## 网站图标为什么重要

1. **辨识度。** 清晰的图标能帮助用户在几十个标签页中找到你的网站，并建立对品牌的信任。
2. **专业形象。** 缺少网站图标时会显示一个通用的占位图标，看起来像是没做完。
3. **搜索曝光。** 搜索引擎会在结果中展示网站图标，独特的图标有助于提升点击率。
4. **减少错误。** 浏览器会自动请求 `/favicon.ico`。如果没有这个文件，服务器日志里就会堆满 404 错误。

## 浏览器如何找到网站图标

页面加载时，浏览器会读取 `<head>` 中 `rel` 属性包含 `icon` 的 `<link>` 标签，并根据 `sizes` 和 `type` 属性以及当前绘制的屏幕选出最合适的图标。如果页面完全没有声明，浏览器会回退到 `https://example.com/favicon.ico`。

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

## 获取任意网站的图标

如果你正在开发一款需要显示其他网站链接的产品，无需自己逐个抓取这些网站。Favicon.is 只需一个 URL 就能返回任意域名的图标：

```html
<img src="https://favicon.is/wikipedia.org" width="32" height="32" alt="Wikipedia">
```
