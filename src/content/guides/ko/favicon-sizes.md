브라우저, 운영체제, 검색 엔진은 모두 서로 다른 크기로 웹사이트 아이콘을 표시합니다. 다행히 어디서나 선명하게 보이려면 몇 개의 파일만 있으면 됩니다.

## 간단한 답

거의 모든 웹사이트에는 다음 세트로 충분합니다.

| 파일 | 크기 | 사용처 |
| --- | --- | --- |
| `favicon.ico` | 32×32(16×16과 48×48도 포함 가능) | 모든 브라우저, 레거시 도구, 자동 `/favicon.ico` 요청 |
| `icon.svg` | 가변 | 최신 브라우저, 모든 크기에서 선명, 다크 모드 지원 가능 |
| `apple-touch-icon.png` | 180×180 | iPhone 및 iPad 홈 화면 |
| `icon-192.png` | 192×192 | Android 홈 화면, 웹 앱 매니페스트 |
| `icon-512.png` | 512×512 | Android 스플래시 화면, 설치 가능한 웹 앱 |

## 일반적인 파비콘 크기와 용도

| 크기 | 표시되는 곳 |
| --- | --- |
| 16×16 | 표준 해상도 화면의 브라우저 탭과 북마크 |
| 32×32 | 고해상도 화면의 브라우저 탭, Windows 작업 표시줄 바로가기 |
| 48×48 | Windows 사이트 아이콘, Google 검색이 권장하는 최소 크기 |
| 96×96, 144×144 | 고밀도 화면의 Google 검색(48의 배수) |
| 180×180 | iOS 및 iPadOS용 `apple-touch-icon` |
| 192×192 | Android Chrome 홈 화면 및 매니페스트 최소 크기 |
| 512×512 | PWA의 스플래시 화면과 앱 스토어용 매니페스트 아이콘 |

## Google 검색 요구 사항

Google은 검색 결과에서 페이지 옆에 파비콘을 표시합니다. Google 가이드라인에 따르면 아이콘은 **정사각형**이어야 하고, 최소 **48×48픽셀**(또는 96×96, 144×144처럼 48의 배수)이어야 하며, Googlebot이 크롤링할 수 있는 고정 URL에서 제공되어야 합니다. SVG 파일도 허용됩니다. 너무 작은 아이콘은 확대되어 흐릿하게 보일 수 있습니다.

## 선명한 아이콘을 위한 팁

- **가장 작은 크기부터 디자인하세요.** 16×16에는 단순한 도형이나 글자 한두 개만 들어갈 공간이 있습니다. 세밀한 디테일과 가는 선은 없애세요.
- **정사각형 전체를 활용하세요.** 여백이 너무 많은 아이콘은 탭에서 아주 작게 보입니다.
- **밝은 배경과 어두운 배경에서 모두 테스트하세요.** 탭, 검색 결과, 홈 화면은 두 가지 배경을 모두 사용합니다.
- **iOS에는 단색 배경을 사용하세요.** iOS는 `apple-touch-icon`의 투명한 영역을 검은색으로 채웁니다.
- **마스커블 아이콘을 지정하세요.** Android는 아이콘을 원형이나 스쿼클 모양으로 자를 수 있습니다. 안전 영역이 있는 아이콘에는 매니페스트에서 `"purpose": "maskable"`을 사용하세요.

## Favicon.is에서 원하는 크기의 아이콘 받기

*다른* 웹사이트의 아이콘을 표시할 때는 필요한 크기를 정확히 요청하세요.

```text
https://favicon.is/github.com?size=32
https://favicon.is/github.com?size=64
https://favicon.is/github.com?larger=true
```

지원되는 값은 16, 32, 48, 64, 128, 256픽셀입니다. 사이트가 게시한 가장 큰 아이콘보다 더 선명해질 수는 없으므로, [파비콘 검사기](../../checker/)로 확인해 보세요.
