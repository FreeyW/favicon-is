**파비콘**(favicon, *favorite icon*의 줄임말)은 웹사이트를 나타내는 작은 이미지입니다. 브라우저 탭, 북마크와 방문 기록, 주소 표시줄, 검색 결과 옆, 그리고 사이트를 바로가기로 저장했을 때 휴대폰 홈 화면에서 볼 수 있습니다.

## 파비콘이 표시되는 곳

- **브라우저 탭.** 탭을 많이 열어 두면 아이콘만으로 탭을 구분하는 경우가 많습니다.
- **북마크와 방문 기록.** 아이콘 덕분에 긴 목록도 한눈에 훑어볼 수 있습니다.
- **검색 결과.** Google을 비롯한 검색 엔진은 모바일과 데스크톱에서 사이트 이름 옆에 파비콘을 표시합니다.
- **홈 화면과 앱 런처.** 사용자가 사이트를 휴대폰에 추가하면 터치 아이콘이 앱 아이콘이 됩니다.
- **기타 앱.** 채팅 앱, 나중에 읽기 서비스, 비밀번호 관리자, 대시보드 등은 모두 파비콘으로 링크를 구분합니다.

## 간략한 역사

파비콘은 1999년 Internet Explorer 5에서 처음 도입되었습니다. 브라우저는 웹사이트 루트에서 `favicon.ico`라는 파일을 찾아 *즐겨찾기*(Favorites) 메뉴에 표시했고, 이름도 여기서 유래했습니다. 이후 HTML에 `<link rel="icon">` 태그가 추가되어 사이트가 아이콘의 위치, 형식, 크기를 직접 지정할 수 있게 되었습니다.

오늘날 웹사이트는 보통 여러 아이콘을 함께 제공합니다. 탭용 작은 ICO 또는 PNG, 어떤 크기로든 확대·축소되는 SVG, iOS용 `apple-touch-icon`, 그리고 Android용으로 웹 앱 매니페스트에 나열하는 더 큰 PNG 파일입니다.

## 파비콘이 중요한 이유

1. **인지도.** 명확한 아이콘은 수십 개의 탭 중에서 내 사이트를 쉽게 찾게 해 주고, 브랜드에 대한 신뢰를 쌓아 줍니다.
2. **전문적인 인상.** 파비콘이 없으면 일반적인 기본 이미지가 표시되어 미완성처럼 보입니다.
3. **검색 노출.** 검색 엔진은 결과에 파비콘을 표시하며, 눈에 띄는 아이콘은 클릭률을 높일 수 있습니다.
4. **오류 감소.** 브라우저는 `/favicon.ico`를 자동으로 요청합니다. 이 파일이 없으면 서버 로그가 404 오류로 가득 찹니다.

## 브라우저가 파비콘을 찾는 방법

페이지가 로드되면 브라우저는 `<head>`에서 `rel` 속성에 `icon`이 포함된 `<link>` 태그를 찾습니다. 그런 다음 `sizes`와 `type` 속성, 그리고 그려질 화면을 기준으로 가장 적합한 후보를 고릅니다. 선언이 전혀 없으면 `https://example.com/favicon.ico`로 대체합니다.

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

## 모든 웹사이트의 파비콘 가져오기

다른 웹사이트로 연결되는 링크를 보여 주는 제품을 만들고 있다면, 각 사이트를 직접 스크레이핑할 필요가 없습니다. Favicon.is는 URL 하나로 모든 도메인의 아이콘을 반환합니다.

```html
<img src="https://favicon.is/wikipedia.org" width="32" height="32" alt="Wikipedia">
```
