**網站圖示**（Favicon，*favorite icon* 的縮寫）是代表一個網站的小圖片。您會在瀏覽器分頁、書籤與瀏覽記錄、網址列以及搜尋結果旁看到它；當您將網站儲存為捷徑時，它也會出現在手機的主畫面上。

## 網站圖示會出現在哪裡

- **瀏覽器分頁。** 開啟許多分頁時，圖示往往是區分它們的唯一線索。
- **書籤與瀏覽記錄。** 有了圖示，即使清單很長也能一眼掃過。
- **搜尋結果。** Google 與其他搜尋引擎會在行動版與桌面版的網站名稱旁顯示網站圖示。
- **主畫面與應用程式啟動器。** 當有人將您的網站加入手機時，觸控圖示就會成為 App 圖示。
- **其他應用程式。** 聊天 App、稍後閱讀服務、密碼管理工具與儀表板都會使用網站圖示來標示連結。

## 簡史

網站圖示由 Internet Explorer 5 於 1999 年推出。這款瀏覽器會在網站根目錄尋找名為 `favicon.ico` 的檔案，並將它顯示在*我的最愛*（Favorites）選單中，這正是名稱的由來。後來 HTML 加入了 `<link rel="icon">` 標籤，讓網站可以自行選擇圖示的位置、格式與尺寸。

現今一個網站通常會提供多個圖示：供分頁使用的小型 ICO 或 PNG、可縮放至任何尺寸的 SVG、供 iOS 使用的 `apple-touch-icon`，以及在 Web 應用程式資訊清單中為 Android 列出的大型 PNG 檔案。

## 網站圖示為什麼重要

1. **辨識度。** 清楚的圖示能幫助使用者在數十個分頁中找到您的網站，並建立對品牌的信任。
2. **專業形象。** 缺少網站圖示時會顯示通用的預留圖示，看起來就像尚未完成。
3. **搜尋能見度。** 搜尋引擎會在結果中顯示網站圖示，獨特的圖示有助於提升點閱率。
4. **減少錯誤。** 瀏覽器會自動請求 `/favicon.ico`。如果沒有這個檔案，伺服器記錄檔就會充滿 404 錯誤。

## 瀏覽器如何找到網站圖示

頁面載入時，瀏覽器會讀取 `<head>` 中 `rel` 屬性包含 `icon` 的 `<link>` 標籤，並根據 `sizes` 與 `type` 屬性以及目前繪製的螢幕，選出最合適的圖示。如果完全沒有宣告，則會改用 `https://example.com/favicon.ico`。

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

## 取得任何網站的圖示

如果您正在開發會顯示其他網站連結的產品，不需要自己逐一爬取每個網站。Favicon.is 只需一個網址，就能回傳任何網域的圖示：

```html
<img src="https://favicon.is/wikipedia.org" width="32" height="32" alt="Wikipedia">
```
