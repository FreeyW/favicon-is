瀏覽器、作業系統與搜尋引擎都會以不同尺寸顯示網站圖示。好消息是：只要少數幾個檔案，就能在各處都清晰銳利。

## 簡短回答

對幾乎所有網站來說，以下這組檔案就足夠了：

| 檔案 | 尺寸 | 使用場合 |
| --- | --- | --- |
| `favicon.ico` | 32×32（也可包含 16×16 與 48×48） | 所有瀏覽器、舊版工具、自動發出的 `/favicon.ico` 請求 |
| `icon.svg` | 可縮放 | 新式瀏覽器，任何尺寸都清晰，可支援深色模式 |
| `apple-touch-icon.png` | 180×180 | iPhone 與 iPad 主畫面 |
| `icon-192.png` | 192×192 | Android 主畫面、Web 應用程式資訊清單 |
| `icon-512.png` | 512×512 | Android 啟動畫面、可安裝的 Web 應用程式 |

## 常見網站圖示尺寸與用途

| 尺寸 | 顯示位置 |
| --- | --- |
| 16×16 | 標準解析度螢幕上的瀏覽器分頁與書籤 |
| 32×32 | 高解析度螢幕上的瀏覽器分頁、Windows 工作列捷徑 |
| 48×48 | Windows 網站圖示；Google Search 建議的最小尺寸 |
| 96×96、144×144 | 高密度螢幕上的 Google Search（48 的倍數） |
| 180×180 | 供 iOS 與 iPadOS 使用的 `apple-touch-icon` |
| 192×192 | Android Chrome 主畫面，也是資訊清單的最小尺寸 |
| 512×512 | 供 PWA 啟動畫面與應用程式商店使用的資訊清單圖示 |

## Google Search 的要求

Google 會在搜尋結果中，將您的網站圖示顯示在網頁旁。根據 Google 的規範，圖示應為**正方形**，至少 **48×48 像素**（或 48 的倍數，例如 96×96 或 144×144），並放在 Googlebot 可以檢索的固定網址上。SVG 檔案也可以使用。過小的圖示會被放大，看起來可能會模糊。

## 讓圖示清晰銳利的技巧

- **先為最小尺寸設計。** 在 16×16 下只容得下簡單的形狀或一兩個字母。請移除細節與細線條。
- **善用整個正方形。** 留白太多的圖示在分頁中會顯得很小。
- **在淺色與深色背景上測試。** 分頁、搜尋結果與主畫面兩種背景都會用到。
- **為 iOS 提供實色背景。** iOS 會以黑色填滿 `apple-touch-icon` 的透明區域。
- **標示可遮罩圖示。** Android 可能會將圖示裁切成圓形或圓角方形（squircle）；對於具有安全區域的圖示，請在資訊清單中使用 `"purpose": "maskable"`。

## 透過 Favicon.is 取得任何尺寸的圖示

顯示*其他*網站的圖示時，請只請求您需要的確切尺寸：

```text
https://favicon.is/github.com?size=32
https://favicon.is/github.com?size=64
https://favicon.is/github.com?larger=true
```

支援的數值為 16、32、48、64、128 與 256 像素。圖示的清晰度取決於網站所發布的最大圖示，可以使用[網站圖示檢查工具](../../checker/)確認。
