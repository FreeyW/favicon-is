फ़ेविकॉन जोड़ने में लगभग दस मिनट लगते हैं। यह गाइड आपको फ़ाइलें बनाने, HTML जोड़ने और नतीजा जाँचने तक हर कदम पर रास्ता दिखाती है।

## 1. अपनी सोर्स इमेज तैयार करें

कम से कम **512×512 पिक्सेल** की एक चौकोर इमेज से शुरू करें; बेहतर हो कि यह आपके लोगो का वेक्टर (SVG) वर्शन हो। इसे सरल बनाएँ: 16 पिक्सेल पर टेक्स्ट और पतली लाइनें गायब हो जाती हैं। कई ब्रांड फ़ेविकॉन के लिए सिर्फ़ एक अक्षर या सिंबल इस्तेमाल करते हैं।

## 2. आइकन फ़ाइलें बनाएँ

अपने डिज़ाइन टूल या किसी फ़ेविकॉन जनरेटर से ये फ़ाइलें एक्सपोर्ट करें:

- `favicon.ico` – 32×32 (चाहें तो अंदर 16×16 और 48×48 के साथ)
- `icon.svg` – स्केलेबल वर्शन
- `apple-touch-icon.png` – ठोस बैकग्राउंड के साथ 180×180
- `icon-192.png` और `icon-512.png` – वेब ऐप मैनिफ़ेस्ट के लिए

इन्हें अपनी वेबसाइट के रूट फ़ोल्डर में रखें (वही फ़ोल्डर जिसमें आपका होम पेज है)।

## 3. HTML टैग जोड़ें

ये लाइनें हर पेज के `<head>` के अंदर पेस्ट करें:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.webmanifest">
```

ज़्यादातर फ़्रेमवर्क और साइट बिल्डर में इसके लिए एक तय जगह होती है: Astro, Next.js और Vite प्रोजेक्ट में `public` फ़ोल्डर, WordPress में Site Identity सेटिंग, या Shopify में थीम सेटिंग।

## 4. वेब ऐप मैनिफ़ेस्ट जोड़ें

अपने आइकन के बगल में `manifest.webmanifest` बनाएँ:

```json
{
  "name": "My Website",
  "icons": [
    { "src": "/icon-192.png", "type": "image/png", "sizes": "192x192" },
    { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512" },
    { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512", "purpose": "maskable" }
  ]
}
```

## 5. नतीजा जाँचें

अपनी साइट को नए ब्राउज़र टैब में खोलें, फिर उसे [Favicon.is चेकर](../../checker/) से जाँचें। यह आपके पेज में घोषित हर आइकन की सूची देता है, जाँचता है कि फ़ाइलें लोड होती हैं या नहीं, और बताता है कि कौन-से साइज़ गायब हैं।

## समस्या का हल: मेरा फ़ेविकॉन अपडेट नहीं हो रहा

ब्राउज़र फ़ेविकॉन को बहुत आक्रामक तरीके से कैश करते हैं। अगर आपने अपना आइकन बदल दिया है, लेकिन अब भी पुराना दिख रहा है:

- URL में एक वर्शन जोड़ें, जैसे `/icon.svg?v=2`, और `<link>` टैग अपडेट करें।
- आइकन URL को सीधे खोलें और फ़ोर्स रीलोड करें।
- ब्राउज़र कैश साफ़ करें या प्राइवेट विंडो में टेस्ट करें।
- सर्च इंजन को आपका होम पेज दोबारा क्रॉल करना होता है; इसमें कई दिन या हफ़्ते लग सकते हैं।

## बोनस: दूसरी वेबसाइटों के फ़ेविकॉन दिखाएँ

अगर आपका ऐप दूसरी साइटों के लिंक दिखाता है, तो उनके आइकन ख़ुद होस्ट करने के बजाय Favicon.is इस्तेमाल करें:

```html
<img src="https://favicon.is/example.com?size=32" width="16" height="16" alt="">
```
