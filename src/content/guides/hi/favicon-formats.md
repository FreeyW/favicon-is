फ़ेविकॉन को कई इमेज फ़ॉर्मैट में सेव किया जा सकता है। हर फ़ॉर्मैट की अपनी खूबियाँ हैं, और सबसे अच्छा सेटअप इनमें से दो या तीन को मिलाकर बनता है।

## ICO

मूल फ़ेविकॉन फ़ॉर्मैट। `.ico` फ़ाइल एक कंटेनर है जिसमें अलग-अलग साइज़ के कई बिटमैप हो सकते हैं, जैसे 16×16, 32×32 और 48×48, ताकि ऑपरेटिंग सिस्टम सही वाला चुन सके।

- **फ़ायदे:** अब तक बने हर ब्राउज़र में सपोर्ट; `/favicon.ico` पर अपने-आप रिक्वेस्ट होता है; कई साइज़ के लिए एक ही फ़ाइल।
- **नुकसान:** फ़ाइल साइज़ बड़ा; वेक्टर स्केलिंग नहीं; बनाने के लिए ख़ास टूल चाहिए।

**कहाँ इस्तेमाल करें:** अपनी साइट के रूट में एक `favicon.ico` के लिए, मुख्य रूप से कम्पैटिबिलिटी के लिए।

## PNG

आज फ़ेविकॉन के लिए PNG सबसे आम फ़ॉर्मैट है। यह पारदर्शिता सपोर्ट करता है और अच्छी तरह कंप्रेस होता है।

- **फ़ायदे:** हर जगह सपोर्ट; किसी भी डिज़ाइन टूल से आसानी से एक्सपोर्ट; 180×180 `apple-touch-icon` और 192×192 व 512×512 मैनिफ़ेस्ट आइकन के लिए आदर्श।
- **नुकसान:** हर साइज़ एक अलग फ़ाइल है; यह अपने पिक्सेल साइज़ से आगे स्केल नहीं होता।

**कहाँ इस्तेमाल करें:** टच आइकन, मैनिफ़ेस्ट आइकन के लिए और उन ब्राउज़र के लिए फ़ॉलबैक के रूप में जो SVG सपोर्ट नहीं करते।

## SVG

SVG एक वेक्टर फ़ॉर्मैट है, इसलिए एक छोटी-सी फ़ाइल हर साइज़ और हर स्क्रीन डेंसिटी पर शार्प रहती है।

- **फ़ायदे:** हर जगह बिल्कुल साफ़; बहुत छोटा फ़ाइल साइज़; CSS मीडिया क्वेरी से डार्क मोड के हिसाब से बदल सकता है।
- **नुकसान:** ब्राउज़र सपोर्ट अभी हर जगह नहीं है, इसलिए ICO या PNG फ़ॉलबैक रखें; बहुत डिटेल वाले लोगो के लिए 16×16 पर अब भी एक सरल वर्शन की ज़रूरत पड़ सकती है।

जब यूज़र डार्क थीम पसंद करता है, तो SVG फ़ेविकॉन अपने रंग बदल सकता है:

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 32 32">
  <style>
    path { fill: #0f172a; }
    @media (prefers-color-scheme: dark) { path { fill: #f8fafc; } }
  </style>
  <path d="M4 4h24v24H4z"/>
</svg>
```

## GIF, JPEG और WebP

ये फ़ॉर्मैट ज़्यादातर आधुनिक ब्राउज़र में काम करते हैं, लेकिन आइकन के लिए इनके फ़ायदे कम हैं। GIF एनिमेशन सपोर्ट करता है, हालाँकि एनिमेटेड फ़ेविकॉन ध्यान भटकाते हैं और हर जगह नहीं दिखते। JPEG पारदर्शिता सपोर्ट नहीं करता। WebP और AVIF कुशल हैं, लेकिन फ़ेविकॉन पढ़ने वाला हर प्लैटफ़ॉर्म इन्हें सपोर्ट नहीं करता।

## आपको कौन-से फ़ॉर्मैट इस्तेमाल करने चाहिए?

आज सबसे भरोसेमंद कॉम्बिनेशन यह है:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.webmanifest">
```

जो ब्राउज़र SVG समझते हैं, वे `icon.svg` इस्तेमाल करेंगे; बाकी `favicon.ico` पर फ़ॉलबैक करेंगे।

## Favicon.is कौन-सा फ़ॉर्मैट लौटाता है?

Favicon.is आइकन को उसी फ़ॉर्मैट में लौटाता है जिसमें वेबसाइट उसे देती है। ज़्यादातर मामलों में यह PNG होता है, लेकिन ICO, SVG, JPEG, GIF या WebP भी हो सकता है। `Content-Type` रिस्पॉन्स हेडर हमेशा बताता है कि आपको कौन-सा फ़ॉर्मैट मिला, और हर फ़ॉर्मैट सामान्य `<img>` टैग में काम करता है।
