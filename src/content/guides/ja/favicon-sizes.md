ブラウザ、OS、検索エンジンは、それぞれ異なるサイズでWebサイトのアイコンを表示します。ただし朗報があります。どこでも鮮明に表示するために必要なファイルは、ほんの数個だけです。

## 結論

ほとんどのWebサイトでは、次のセットがあれば十分です。

| ファイル | サイズ | 使われる場所 |
| --- | --- | --- |
| `favicon.ico` | 32×32（16×16と48×48も格納可能） | すべてのブラウザ、従来のツール、`/favicon.ico` への自動リクエスト |
| `icon.svg` | 可変 | モダンブラウザ。どのサイズでも鮮明で、ダークモードにも対応可能 |
| `apple-touch-icon.png` | 180×180 | iPhoneとiPadのホーム画面 |
| `icon-192.png` | 192×192 | Androidのホーム画面、Webアプリマニフェスト |
| `icon-512.png` | 512×512 | Androidのスプラッシュ画面、インストール可能なWebアプリ |

## よく使われるファビコンのサイズと用途

| サイズ | 表示される場所 |
| --- | --- |
| 16×16 | 標準解像度の画面でのブラウザのタブとブックマーク |
| 32×32 | 高解像度の画面でのブラウザのタブ、Windowsのタスクバーのショートカット |
| 48×48 | Windowsのサイトアイコン。Google検索が推奨する最小サイズ |
| 96×96、144×144 | 高密度画面でのGoogle検索（48の倍数） |
| 180×180 | iOSとiPadOS向けの `apple-touch-icon` |
| 192×192 | AndroidのChromeのホーム画面。マニフェストの最小サイズ |
| 512×512 | PWAのスプラッシュ画面やアプリストア向けのマニフェストアイコン |

## Google検索の要件

Googleは、検索結果のページの横にファビコンを表示します。Googleのガイドラインによると、アイコンは**正方形**で、**48×48ピクセル以上**（または96×96や144×144など48の倍数）であり、Googlebotがクロールできる安定したURLで公開されている必要があります。SVGファイルも使用できます。非常に小さなアイコンは拡大されるため、ぼやけて見えることがあります。

## 鮮明なアイコンを作るコツ

- **最小サイズから先にデザインする**：16×16には、シンプルな図形か1〜2文字を入れる余裕しかありません。細かなディテールや細い線は取り除きましょう。
- **正方形全体を使う**：余白が多すぎるアイコンは、タブの中でとても小さく見えます。
- **明るい背景と暗い背景の両方でテストする**：タブ、検索結果、ホーム画面では、どちらの背景も使われます。
- **iOS向けには背景を塗りつぶす**：iOSは `apple-touch-icon` の透明な部分を黒で塗りつぶします。
- **マスカブルアイコンを指定する**：Androidはアイコンを円形やスクワークル（角丸の正方形）に切り抜くことがあります。セーフゾーンを確保したアイコンには、マニフェストで `"purpose": "maskable"` を指定しましょう。

## Favicon.isで任意のサイズのアイコンを取得する

*ほかの*Webサイトのアイコンを表示する場合は、必要なサイズを正確に指定してリクエストしましょう。

```text
https://favicon.is/github.com?size=32
https://favicon.is/github.com?size=64
https://favicon.is/github.com?larger=true
```

指定できる値は、16、32、48、64、128、256ピクセルです。サイトが公開している最大のアイコン以上に鮮明にはならないため、[ファビコンチェッカー](../../checker/)で確認してみてください。
