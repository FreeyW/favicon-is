ブックマーク管理ツール、リンクまとめページ、ダッシュボード、ブラウザ拡張機能のどれを作るにしても、遅かれ早かれほかのWebサイトのアイコンが必要になります。ここでは、最も手間のかかる方法から最も簡単な方法まで、選択肢を紹介します。

## 1. /favicon.icoをリクエストする

最も古い慣例です。多くのサイトは今でもルートでアイコンを配信しています。

```text
https://example.com/favicon.ico
```

**長所**：サードパーティに依存しない。**短所**：このファイルがないサイトはかなりの割合に上り、あっても16×16や32×32ピクセルしかないことが多く、ファイルがなければ画像切れになる。

## 2. ページのHTMLを読み取る

確実な方法は、トップページをダウンロードして `<link rel="icon">`、`<link rel="apple-touch-icon">`、Webアプリマニフェストを探し、最適なサイズを選ぶことです。

```js
const html = await fetch('https://example.com').then((r) => r.text());
const links = [...html.matchAll(/<link[^>]+rel=["'][^"']*icon[^"']*["'][^>]*>/gi)];
```

**長所**：サイトが実際に宣言しているアイコンを見つけられる。**短所**：リダイレクト、相対URL、タイムアウト、ボットをブロックするサイト、キャッシュ、フォールバックをすべて自分で処理する必要がある。さらに、CORSの制約によりブラウザからは実行できない。

## 3. ブラウザ拡張機能のAPIを使う

Chrome拡張機能では、`favicon` 権限と `chrome-extension://<id>/_favicon/?pageUrl=…` を使って、ブラウザがすでに把握しているアイコンを取得できます。ただし、この方法は拡張機能の中でしか使えず、ユーザーが訪問したことのあるサイトにしか対応していません。

## 4. 検索エンジンのファビコンサービスを使う

GoogleとDuckDuckGoは、クロール中に収集したアイコンを公開しています。

```text
https://www.google.com/s2/favicons?domain=example.com&sz=64
https://icons.duckduckgo.com/ip3/example.com.ico
```

**長所**：高速で、対応範囲が広い。**短所**：非公式でドキュメントもなく、サイズや形式を細かく制御できず、何が返されたかの情報も得られない。

## 5. Favicon.isを使う

Favicon.isは、上記のすべてをひとつのURLにまとめています。Googleのファビコンキャッシュを確認し、サイトのHTMLを読み取り、`/favicon.ico` を試し、結果をCloudflare R2に保存して、必ず画像を返します。

```html
<img src="https://favicon.is/example.com" width="32" height="32" alt="">
```

- `?size=16` 〜 `?size=256` でサイズを選ぶか、`?larger=true` を使います。
- `?original=true` を付けると、Googleを経由せずにサイト自身のアイコン宣言を読み取ります。
- `X-Source` ヘッダーで、アイコンの取得元を確認できます。
- IANAルートゾーンデータベースに登録されたTLDのドメインのみを検索するため、入力ミスやプライベートな名前にはすぐにデフォルトアイコンが返されます。

すべてのオプションは[APIドキュメント](../../docs/)で確認できます。また、[使用例](../../examples/)からコードをコピーすることもできます。
