ファビコンの設置にかかる時間は10分ほどです。このガイドでは、ファイルの作成からHTMLの追加、結果の確認までを順に説明します。

## 1. 元画像を用意する

**512×512ピクセル**以上の正方形の画像から始めましょう。理想はロゴのベクター（SVG）版です。デザインはシンプルにします。16ピクセルでは、文字や細い線は判別できなくなります。多くのブランドは、ファビコンに1文字やシンボルだけを使っています。

## 2. アイコンファイルを作成する

デザインツールやファビコンジェネレーターから、次のファイルを書き出します。

- `favicon.ico` – 32×32（必要に応じて16×16と48×48も格納）
- `icon.svg` – 拡大縮小できるバージョン
- `apple-touch-icon.png` – 180×180、背景は塗りつぶし
- `icon-192.png` と `icon-512.png` – Webアプリマニフェスト用

これらをWebサイトのルートフォルダー（トップページと同じフォルダー）に置きます。

## 3. HTMLタグを追加する

すべてのページの `<head>` 内に、次の行を貼り付けます。

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.webmanifest">
```

ほとんどのフレームワークやサイトビルダーには、そのための専用の場所があります。Astro、Next.js、Viteのプロジェクトでは `public` フォルダー、WordPressでは「サイト基本情報」の設定、Shopifyではテーマの設定です。

## 4. Webアプリマニフェストを追加する

アイコンと同じ場所に `manifest.webmanifest` を作成します。

```json
{
  "name": "My Website",
  "icons": [
    { "src": "/icon-192.png", "type": "image/png", "sizes": "192x192" },
    { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512" },
    { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512", "purpose": "maskable" }
  ]
}
```

## 5. 結果を確認する

ブラウザの新しいタブでサイトを開き、[Favicon.isのチェッカー](../../checker/)にかけてみましょう。ページが宣言しているすべてのアイコンを一覧表示し、ファイルが読み込めるかを確認して、不足しているサイズを教えてくれます。

## トラブルシューティング：ファビコンが更新されない

ブラウザはファビコンを非常に強力にキャッシュします。アイコンを差し替えたのに古いものが表示される場合は、次を試してください。

- `/icon.svg?v=2` のようにURLにバージョンを付け、`<link>` タグを更新する。
- アイコンのURLを直接開き、強制的に再読み込みする。
- ブラウザのキャッシュをクリアするか、プライベートウィンドウでテストする。
- 検索エンジンには、トップページを再クロールしてもらう必要があります。これには数日から数週間かかることがあります。

## おまけ：ほかのWebサイトのファビコンを表示する

アプリでほかのサイトへのリンクを一覧表示する場合は、各サイトのアイコンを自分でホスティングする代わりに、Favicon.isを使いましょう。

```html
<img src="https://favicon.is/example.com?size=32" width="16" height="16" alt="">
```
