**ファビコン**（favicon：*favorite icon* の略）とは、Webサイトを表す小さな画像のことです。ブラウザのタブ、ブックマークや履歴、アドレスバー、検索結果の横、そしてサイトをショートカットとして保存したときのスマートフォンのホーム画面などで目にします。

## ファビコンが表示される場所

- **ブラウザのタブ**：多くのタブを開いているとき、タブを見分ける手がかりがアイコンだけということもよくあります。
- **ブックマークと履歴**：アイコンがあれば、長いリストもひと目で見渡せます。
- **検索結果**：Googleなどの検索エンジンは、モバイルでもデスクトップでも、サイト名の横にファビコンを表示します。
- **ホーム画面とアプリランチャー**：ユーザーがサイトをスマートフォンに追加すると、タッチアイコンがアプリアイコンになります。
- **その他のアプリ**：チャットアプリ、あとで読むサービス、パスワードマネージャー、ダッシュボードなどは、いずれもリンクの目印としてファビコンを使っています。

## ファビコンの歴史

ファビコンは、1999年にInternet Explorer 5で導入されました。ブラウザはWebサイトのルートにある `favicon.ico` というファイルを探し、それを「お気に入り」（*Favorites*）メニューに表示していました。これが名前の由来です。その後、HTMLに `<link rel="icon">` タグが加わり、サイト側でアイコンの場所、形式、サイズを指定できるようになりました。

現在では、ひとつのWebサイトが複数のアイコンを用意するのが一般的です。タブ用の小さなICOまたはPNG、どのサイズにも拡大縮小できるSVG、iOS向けの `apple-touch-icon`、そしてAndroid向けにWebアプリマニフェストに記載する大きめのPNGファイルなどです。

## ファビコンが重要な理由

1. **認知性**：わかりやすいアイコンは、たくさんのタブの中から自分のサイトを見つけてもらう助けになり、ブランドへの信頼にもつながります。
2. **プロフェッショナルな印象**：ファビコンがないと汎用のプレースホルダーが表示され、未完成のように見えてしまいます。
3. **検索での視認性**：検索エンジンは検索結果にファビコンを表示します。特徴的なアイコンはクリック率の向上につながることがあります。
4. **エラーの削減**：ブラウザは `/favicon.ico` を自動的にリクエストします。このファイルがないと、サーバーログが404エラーで埋まってしまいます。

## ブラウザがファビコンを見つける仕組み

ページを読み込むと、ブラウザは `<head>` 内から、`rel` 属性に `icon` を含む `<link>` タグを探します。そして `sizes` 属性と `type` 属性、描画先の画面に基づいて最適な候補を選びます。宣言がまったくない場合は、`https://example.com/favicon.ico` にフォールバックします。

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

## あらゆるWebサイトのファビコンを取得する

ほかのWebサイトへのリンクを表示するプロダクトを開発している場合でも、各サイトを自分でスクレイピングする必要はありません。Favicon.isなら、URLひとつで任意のドメインのアイコンを取得できます。

```html
<img src="https://favicon.is/wikipedia.org" width="32" height="32" alt="Wikipedia">
```
