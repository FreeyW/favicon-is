Фавикон можно сохранить в нескольких форматах изображений. У каждого есть свои сильные стороны, а лучшая конфигурация сочетает два или три из них.

## ICO

Исходный формат фавиконов. Файл `.ico` — это контейнер, в котором может быть несколько растровых изображений разных размеров, например 16×16, 32×32 и 48×48, чтобы операционная система могла выбрать подходящее.

- **Плюсы:** поддерживается всеми браузерами, когда-либо созданными; автоматически запрашивается по адресу `/favicon.ico`; один файл для нескольких размеров.
- **Минусы:** больший размер файла; нет векторного масштабирования; для создания нужен специальный инструмент.

**Для чего использовать:** один файл `favicon.ico` в корне сайта — в основном ради совместимости.

## PNG

PNG — самый распространённый формат фавиконов сегодня. Он поддерживает прозрачность и хорошо сжимается.

- **Плюсы:** универсальная поддержка; легко экспортировать из любого графического редактора; идеально подходит для `apple-touch-icon` 180×180 и иконок манифеста 192×192 и 512×512.
- **Минусы:** каждый размер — отдельный файл; не масштабируется больше своего размера в пикселях.

**Для чего использовать:** touch-иконки, иконки манифеста и запасной вариант для браузеров, которые не поддерживают SVG.

## SVG

SVG — векторный формат, поэтому один небольшой файл остаётся чётким в любом размере и при любой плотности пикселей экрана.

- **Плюсы:** идеальная чёткость везде; крошечный размер файла; может реагировать на тёмную тему с помощью медиазапросов CSS.
- **Минусы:** поддержка в браузерах пока не повсеместная, поэтому оставьте запасной вариант в ICO или PNG; очень детализированным логотипам всё равно может понадобиться упрощённая версия для 16×16.

SVG-фавикон может менять цвета, когда пользователь предпочитает тёмную тему:

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 32 32">
  <style>
    path { fill: #0f172a; }
    @media (prefers-color-scheme: dark) { path { fill: #f8fafc; } }
  </style>
  <path d="M4 4h24v24H4z"/>
</svg>
```

## GIF, JPEG и WebP

Эти форматы работают в большинстве современных браузеров, но для иконок у них мало преимуществ. GIF поддерживает анимацию, однако анимированные фавиконы отвлекают и показываются не везде. JPEG не поддерживает прозрачность. WebP и AVIF эффективны, но поддерживаются не всеми платформами, которые читают фавиконы.

## Какие форматы использовать?

Самое надёжное сочетание на сегодня:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.webmanifest">
```

Браузеры, которые понимают SVG, используют `icon.svg`, остальные переключаются на `favicon.ico`.

## В каком формате отвечает Favicon.is?

Favicon.is возвращает иконку в том формате, который предоставляет сайт. Чаще всего это PNG, но может быть ICO, SVG, JPEG, GIF или WebP. Заголовок ответа `Content-Type` всегда сообщает, какой формат вы получили, и любой формат работает в обычном теге `<img>`.
