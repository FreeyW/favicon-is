Браузеры, операционные системы и поисковые системы показывают иконки сайтов в разных размерах. Хорошая новость: чтобы иконка везде выглядела чётко, достаточно нескольких файлов.

## Коротко

Почти для любого сайта хватит такого набора:

| Файл | Размер | Где используется |
| --- | --- | --- |
| `favicon.ico` | 32×32 (может также содержать 16×16 и 48×48) | Все браузеры, устаревшие инструменты, автоматический запрос `/favicon.ico` |
| `icon.svg` | Масштабируемый | Современные браузеры, чёткость в любом размере, поддержка тёмной темы |
| `apple-touch-icon.png` | 180×180 | Главный экран iPhone и iPad |
| `icon-192.png` | 192×192 | Главный экран Android, манифест веб-приложения |
| `icon-512.png` | 512×512 | Заставки Android, устанавливаемые веб-приложения |

## Популярные размеры фавиконов и их назначение

| Размер | Где отображается |
| --- | --- |
| 16×16 | Вкладки и закладки браузера на экранах стандартного разрешения |
| 32×32 | Вкладки браузера на экранах высокого разрешения, ярлыки на панели задач Windows |
| 48×48 | Иконки сайтов в Windows; минимальный размер, рекомендуемый Google Search |
| 96×96, 144×144 | Google Search на экранах с высокой плотностью пикселей (кратно 48) |
| 180×180 | `apple-touch-icon` для iOS и iPadOS |
| 192×192 | Главный экран Android в Chrome и минимальный размер для манифеста |
| 512×512 | Иконка манифеста для заставок и магазинов приложений для PWA |

## Требования Google Search

Google показывает ваш фавикон рядом со страницами в результатах поиска. Согласно рекомендациям Google, иконка должна быть **квадратной**, размером не менее **48×48 пикселей** (или кратным 48, например 96×96 или 144×144) и доступной по постоянному URL, который разрешено сканировать Googlebot. Файлы SVG тоже принимаются. Очень маленькие иконки увеличиваются и могут выглядеть размытыми.

## Советы для чётких иконок

- **Начинайте с самого маленького размера.** В 16×16 помещается только простая фигура или одна-две буквы. Уберите мелкие детали и тонкие линии.
- **Используйте весь квадрат.** Иконки со слишком большими отступами выглядят во вкладках крошечными.
- **Проверяйте на светлом и тёмном фоне.** Во вкладках, результатах поиска и на главных экранах встречаются оба варианта.
- **Дайте iOS сплошной фон.** iOS заливает прозрачные области `apple-touch-icon` чёрным.
- **Отмечайте maskable-иконки.** Android может обрезать иконки до круга или скруглённого квадрата; для иконок с безопасной зоной укажите в манифесте `"purpose": "maskable"`.

## Иконки любого размера из Favicon.is

Когда вы показываете иконки *других* сайтов, запрашивайте ровно тот размер, который нужен:

```text
https://favicon.is/github.com?size=32
https://favicon.is/github.com?size=64
https://favicon.is/github.com?larger=true
```

Поддерживаются значения 16, 32, 48, 64, 128 и 256 пикселей. Иконка не может быть чётче самой большой иконки, которую публикует сайт, поэтому проверьте её с помощью [инструмента проверки фавиконов](../../checker/).
