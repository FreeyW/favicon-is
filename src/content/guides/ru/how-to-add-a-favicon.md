Добавление фавикона занимает около десяти минут. Это руководство проведёт вас через создание файлов, добавление HTML и проверку результата.

## 1. Подготовьте исходное изображение

Начните с квадратного изображения размером не менее **512×512 пикселей**, в идеале — с векторной (SVG) версии логотипа. Упростите его: при 16 пикселях текст и тонкие линии исчезают. Многие бренды используют для фавикона одну букву или символ.

## 2. Создайте файлы иконок

Экспортируйте эти файлы из графического редактора или генератора фавиконов:

- `favicon.ico` — 32×32 (по желанию с 16×16 и 48×48 внутри)
- `icon.svg` — масштабируемая версия
- `apple-touch-icon.png` — 180×180 со сплошным фоном
- `icon-192.png` и `icon-512.png` — для манифеста веб-приложения

Положите их в корневую папку сайта (ту же, где лежит главная страница).

## 3. Добавьте HTML-теги

Вставьте эти строки в `<head>` каждой страницы:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.webmanifest">
```

В большинстве фреймворков и конструкторов сайтов для этого есть специальное место: папка `public` в проектах на Astro, Next.js и Vite, настройки «Свойства сайта» (Site Identity) в WordPress или настройки темы в Shopify.

## 4. Добавьте манифест веб-приложения

Создайте файл `manifest.webmanifest` рядом с иконками:

```json
{
  "name": "My Website",
  "icons": [
    { "src": "/icon-192.png", "type": "image/png", "sizes": "192x192" },
    { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512" },
    { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512", "purpose": "maskable" }
  ]
}
```

## 5. Проверьте результат

Откройте сайт в новой вкладке браузера, а затем прогоните его через [проверку фавиконов Favicon.is](../../checker/). Она покажет все иконки, объявленные на странице, проверит, загружаются ли файлы, и подскажет, каких размеров не хватает.

## Если фавикон не обновляется

Браузеры очень агрессивно кэшируют фавиконы. Если вы заменили иконку, но всё ещё видите старую:

- Добавьте к URL версию, например `/icon.svg?v=2`, и обновите теги `<link>`.
- Откройте URL иконки напрямую и принудительно перезагрузите страницу.
- Очистите кэш браузера или проверьте в приватном окне.
- Поисковым системам нужно заново просканировать вашу главную страницу; это может занять дни или недели.

## Бонус: показывайте фавиконы других сайтов

Если ваше приложение выводит ссылки на другие сайты, используйте Favicon.is, а не размещайте их иконки у себя:

```html
<img src="https://favicon.is/example.com?size=32" width="16" height="16" alt="">
```
