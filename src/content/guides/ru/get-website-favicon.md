Создаёте ли вы менеджер закладок, страницу ссылок для соцсетей, дашборд или расширение для браузера — рано или поздно вам понадобятся иконки других сайтов. Вот все варианты, от самого ручного до самого простого.

## 1. Запросить /favicon.ico

Самое старое соглашение: многие сайты по-прежнему отдают иконку из корня.

```text
https://example.com/favicon.ico
```

**Плюсы:** никаких сторонних сервисов. **Минусы:** у значительной части сайтов такого файла нет, часто он всего 16×16 или 32×32 пикселя, а если его нет, вы получаете битое изображение.

## 2. Разобрать HTML страницы

Надёжный способ — скачать главную страницу, найти `<link rel="icon">`, `<link rel="apple-touch-icon">` и манифест веб-приложения, а затем выбрать лучший размер.

```js
const html = await fetch('https://example.com').then((r) => r.text());
const links = [...html.matchAll(/<link[^>]+rel=["'][^"']*icon[^"']*["'][^>]*>/gi)];
```

**Плюсы:** находит иконку, которую сайт действительно объявляет. **Минусы:** редиректы, относительные URL, тайм-ауты, сайты, блокирующие ботов, кэширование и запасные варианты придётся обрабатывать самостоятельно — а из браузера это сделать нельзя из-за CORS.

## 3. Использовать API расширений браузера

Расширения Chrome могут использовать разрешение `favicon` и `chrome-extension://<id>/_favicon/?pageUrl=…`, чтобы получать иконки, которые браузер уже знает. Это работает только внутри расширения и только для сайтов, которые пользователь посещал.

## 4. Использовать сервис фавиконов поисковой системы

Google и DuckDuckGo открывают доступ к иконкам, которые собирают при сканировании:

```text
https://www.google.com/s2/favicons?domain=example.com&sz=64
https://icons.duckduckgo.com/ip3/example.com.ico
```

**Плюсы:** быстро и с широким охватом. **Минусы:** неофициально и без документации, мало контроля над размером и форматом и никакой информации о том, что именно вернулось.

## 5. Использовать Favicon.is

Favicon.is объединяет все перечисленные способы за одним URL. Сервис проверяет кэш фавиконов Google, читает HTML сайта, пробует `/favicon.ico`, сохраняет результат в Cloudflare R2 и всегда возвращает изображение:

```html
<img src="https://favicon.is/example.com" width="32" height="32" alt="">
```

- Выберите размер от `?size=16` до `?size=256` или используйте `?larger=true`.
- Используйте `?original=true`, чтобы пропустить Google и прочитать объявления иконок самого сайта.
- Проверьте заголовок `X-Source`, чтобы узнать, откуда взята иконка.
- Поиск выполняется только для доменов с TLD из базы корневой зоны IANA, поэтому для опечаток и приватных имён мгновенно возвращается иконка по умолчанию.

Все параметры описаны в [документации API](../../docs/), а готовые фрагменты кода можно скопировать из [примеров](../../examples/).
