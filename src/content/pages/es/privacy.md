Esta política explica qué información trata Favicon.is cuando usas la API de favicons o visitas este sitio web. En resumen: recopilamos lo mínimo posible y no vendemos datos.

## Solicitudes de iconos

Cuando una aplicación o un navegador solicita un icono, como `https://favicon.is/example.com`, tratamos:

- **El dominio y los parámetros solicitados**, para encontrar y devolver el icono. El dominio y el icono se guardan en nuestra caché (Cloudflare R2) para poder servirlos de nuevo rápidamente.
- **Datos técnicos de la solicitud**, como la dirección IP, el user agent y la hora, que nuestro proveedor de alojamiento, Cloudflare, trata para entregar la respuesta, proteger el servicio contra abusos y elaborar estadísticas agregadas. No usamos estos datos para identificar a personas.

Las respuestas de iconos no establecen cookies.

## Obtención de iconos de otros sitios web

Para encontrar un icono, nuestros servidores pueden contactar con el servicio de favicons de Google o con el sitio web solicitado. Estas solicitudes salen de nuestros servidores, no de tu dispositivo, y solo contienen el nombre de dominio. Tu dirección IP no se transmite.

El comprobador de favicons funciona de otra manera: muestra en tu navegador los iconos del sitio web que compruebas, así que tu navegador carga esas imágenes directamente desde ese sitio.

## Visitas a este sitio web

- **Analítica.** Usamos un script de analítica respetuoso con la privacidad y sin cookies para contar las páginas vistas. No te sigue de un sitio web a otro.
- **Publicidad.** Algunas páginas pueden mostrar anuncios de Google AdSense. Google puede usar cookies para mostrar y medir anuncios; consulta [cómo utiliza Google la información de los sitios que usan sus servicios](https://policies.google.com/technologies/partner-sites). Puedes gestionar la personalización de anuncios en la configuración de tu cuenta de Google.
- **Preferencias.** Tu elección de tema (claro u oscuro) se guarda en el almacenamiento local de tu navegador y nunca se nos envía.

## Conservación de datos

Los iconos en caché se conservan mientras sean útiles y se actualizan con regularidad. Cloudflare conserva los registros de solicitudes durante un periodo limitado, según sus propias políticas de conservación.

## Tus derechos

Según dónde vivas, es posible que tengas derecho a acceder a tus datos personales, rectificarlos o eliminarlos, y a oponerte a su tratamiento. Como no vinculamos las solicitudes con personas, normalmente no conservamos datos personales que puedan atribuirse a ti, pero aun así puedes contactarnos con los datos que aparecen a continuación.

## Cambios

Podemos actualizar esta política cuando cambie el servicio. La fecha que aparece al principio de esta página indica la última revisión.
